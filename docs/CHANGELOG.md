# 变更记录（Changelog）

当前版本：**v3.6.0**

版本号为三位 `v大功能.小功能.小bug`（例如 `v0.1.0`），只递增、不改写已发布条目。

| 位 | 何时 +1 | 同时发生什么 |
|----|---------|--------------|
| **大功能**（第一位） | 新的核心能力或架构级变化（新循环、新工具子系统、新前端形态等） | 后两位归零 |
| **小功能**（第二位） | 在现有大功能上增强（新内置工具、新动画组、新文档子系统、CLI 子命令等） | 第三位归零 |
| **小 bug**（第三位） | 修正错误、笔误、不一致，不引入新能力 | 只动第三位 |

约定：

1. 每次改动（含只改文档）都必须新增一条，日期用当天（北京时间）。
2. 一条记录只对应一次版本跳动；同一天多次独立改动就发多个版本，不要把不相关的事揉进一条。
3. 实现代码的 `__version__`、`pyproject.toml` 的 `version`、`wavecode --version` **必须与本文件最新版本一致**（不含 `v` 前缀，如 `0.2.0`）。
4. 产品显示名为 **WaveCode**；Python 包名仍是 `coding_agent`。
5. 未实现的计划不要写进 Changelog；只记录已经落到仓库里的变化。

设计阶段视为一次交付，不保留中间草稿版本。第一次可运行实现合并进主线时升 **大功能** 到 `v1.0.0`。
